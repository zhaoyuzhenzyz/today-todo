# 今日待办

一个不联网、零依赖、数据全在本地的待办清单。三种形态，代码同源：

| 形态 | 文件 | 适用场景 |
|---|---|---|
| 浏览器版 | `today-todo.html` | 双击即用，不装任何东西 |
| 桌面悬浮版 | `desktop-todo/` | 常驻桌面、始终置顶、随手记录 |
| 安装包 | `dist/`（本地构建） | 建桌面/开始菜单快捷方式 |

---

## 浏览器版

单个 HTML 文件，无外部依赖、无 CDN、无网络请求。双击用浏览器打开即可。

- 新增（`Enter` 或按钮）、勾选完成、**双击标题编辑**、删除
- 剩余计数 + 总数 + 进度条
- 全部 / 未完成 / 已完成筛选，清除已完成
- 深色 / 浅色主题切换，偏好记忆
- 跨标签页同步
- 数据存 `localStorage`，key 为 `today-todo.v1`

空白或纯空格的任务不会被添加，输入框会抖动提示。

---

## 桌面悬浮版

常驻桌面的浮窗，随时能看见、随手能记。

### 两种窗口形态，一键切换

| | 悬浮模式（默认） | 普通窗口模式 |
|---|---|---|
| 边框 | 无边框 / 圆角悬浮卡片 | 系统标准标题栏 |
| 位置 | 始终置顶，不挡操作 | 可最小化，正常层级 |
| 拖动 | 按住卡片任意空白处拖动 | 拖标题栏 |
| 任务栏 | 不占任务栏，只在托盘 | 占任务栏 |
| 尺寸 | 右下角手柄拖拽缩放 | 系统边框缩放 |

切换后窗口尺寸、位置、模式都会记住，下次启动原样恢复。

### 操作速查

| 想做什么 | 怎么做 |
|---|---|
| 新增任务 | 输入框输入 → `Enter` 或点「添加」 |
| 完成 / 取消 | 点左侧方框 |
| 编辑标题 | **双击标题文字**，或鼠标移到该行点铅笔图标 |
| 删除单条 | 鼠标移到该行 → 点右侧垃圾桶 |
| 移动窗口 | 按住卡片空白处拖动（悬浮模式） |
| 临时藏起来 | 顶栏 ✕，或 `Esc` |
| 重新唤出 | 双击托盘图标，或托盘右键「显示窗口」 |
| 彻底退出 | 托盘右键 → 退出应用 |

**快捷键**：`Enter` 添加 · `Esc` 依次退出编辑 → 清空输入 → 收起设置 → 隐藏窗口

编辑的几个细节：

- 双击标题进入行内编辑，光标落在末尾，输入框全宽替换标题
- `Enter` 保存，`Esc` 取消（不会误触隐藏窗口），点别处失焦也自动保存
- **内容清空后回车 = 删除该条**
- 首尾空格自动裁剪，最多 200 字
- 同一时刻只有一行处于编辑态，去编辑另一行时上一行自动提交
- 已完成的任务同样可以改名，不会因此被取消勾选

### 其他能力

- **设置面板**：透明度 40%–100% 无级调节、开机自启开关、窗口模式切换
- **托盘**：单击显隐、右键菜单
- **边缘吸附**：拖到屏幕边缘 14px 内自动吸附
- **副屏保护**：拔掉副屏后窗口自动拉回主屏可见区域
- **单实例**：重复启动会激活已有窗口，不会开出第二个
- **静默自启**：开机自启带 `--autostart` 参数，启动后驻留托盘不抢焦点

### 数据存在哪里

```
%APPDATA%\今日待办\
├── state.json       窗口位置、尺寸、模式、透明度
└── Local Storage\   任务清单
```

完全离线，不联网、不上传。关窗口不丢数据，只有托盘「退出应用」才真正结束进程。

## 从源码构建

```bash
cd desktop-todo
npm install
npm start          # 开发运行
npm run dist       # 打包安装版 + 免安装版到 dist/
```

需要 Node.js 18+。首次 `npm install` 会下载 Electron（约 100MB+）。

### 打包产物

- `dist/今日待办-安装程序-<version>.exe` —— NSIS 安装版，建桌面 + 开始菜单快捷方式，单用户安装免管理员
- `dist/今日待办-免安装-<version>.exe` —— 便携版，不写注册表，可放 U 盘

卸载时任务数据会保留（`deleteAppDataOnUninstall: false`），重装后待办还在。彻底清除需手动删 `%APPDATA%\今日待办`。

> 打包产物未购买代码签名证书，首次运行 Windows SmartScreen 会提示「未知发布者」，点「更多信息」→「仍要运行」即可。这是未签名的正常现象。

## 目录结构

```
.
├── today-todo.html          浏览器版（单文件）
├── desktop-todo/
│   ├── main.js              主进程：窗口创建、模式切换、托盘、状态持久化、开机自启
│   ├── preload.js           安全桥接层（contextIsolation 开启，渲染层无 Node 权限）
│   ├── renderer/index.html  界面与交互逻辑（单文件，零外部依赖）
│   ├── after-pack.js        打包钩子：把图标与版本信息写入 exe
│   ├── apply-icon.js        手动补图标工具（打包异常时备用）
│   ├── build/               应用图标（9 种尺寸 16~256px）
│   ├── README.md            桌面版详细文档
│   └── package.json         依赖与打包配置
└── tests/                   自动化测试（CDP 驱动真实窗口，见 tests/README.md）
```

## 技术要点

- **Electron 33**，`contextIsolation: true` + `nodeIntegration: false`，渲染进程无文件系统与 Node 访问权
- 悬浮透明窗口通过 `transparent` + `skipTaskbar` + `setAlwaysOnTop('floating')` 实现，并 `setVisibleOnAllWorkspaces` 支持虚拟桌面
- 拖动用 CSS `-webkit-app-region: drag`，比 IPC 位移更跟手、无延迟累积；所有交互元素显式声明 `no-drag`
- 模式切换采用「销毁并按新模式重建窗口」，不是改属性——因为 `frame` / `transparent` 创建后不可变
- 图标嵌入走 `afterPack` 钩子 + `rcedit`，在应用目录打包完成、安装程序生成之前写入，确保安装包/便携包/程序本体三者图标一致

## 关于上架应用商店

已评估，**决定不上架**。

待办清单属于 Windows 桌面软件，国内安卓系商店（华为/小米/OPPO/vivo/应用宝）那套流程只收 APK/HAP，投不进去；且需软著（20–40 工作日）、工信部备案等重资质，对一个桌面小工具不划算。

Microsoft Store 技术上可行（Electron 官方支持 MSIX），但需代码签名证书，且 MSIX 容器内 `setLoginItemSettings` 会失效（要换 WinRT StartupTask），悬浮置顶行为也需实测。投入产出不对等，维持直发 exe。
