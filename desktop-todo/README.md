# 今日待办 · 桌面悬浮版

一个常驻桌面的待办浮窗，随时能看见、随手能记录。

---

## 两种形态，一键切换

| | 悬浮模式（默认） | 普通窗口模式 |
|---|---|---|
| 边框 | 无边框 / 圆角悬浮卡片 | 系统标准标题栏 |
| 位置 | 始终置顶，不挡操作 | 可最小化，正常层级 |
| 拖动 | 按住卡片任意空白处拖动 | 拖标题栏 |
| 任务栏 | 不占任务栏，只在托盘 | 占任务栏 |
| 尺寸 | 右下角手柄拖拽缩放 | 系统边框缩放 |
| 切换 | 顶栏 ↗ 按钮，或设置面板「退出悬浮」 | 顶栏 ↗ 按钮，或托盘菜单 |

切换后窗口尺寸、位置、模式都会记住，下次启动原样恢复。

---

## 操作速查

| 想做什么 | 怎么做 |
|---|---|
| 新增任务 | 输入框输入 → `Enter` 或点「添加」 |
| 完成 / 取消 | 点左侧方框 |
| **编辑标题** | **双击标题文字**，或鼠标移到该行点铅笔图标 |
| 删除单条 | 鼠标移到该行 → 点右侧垃圾桶 |
| 清除全部已完成 | 底部「清除已完成」 |
| 筛选 | 全部 / 未完成 / 已完成 |
| 移动窗口 | 按住卡片空白处拖动（悬浮模式） |
| 调整大小 | 右下角斜纹手柄（悬浮模式） |
| 临时藏起来 | 顶栏 ✕，或 `Esc` |
| 重新唤出 | 双击托盘图标，或托盘右键「显示窗口」 |
| 彻底退出 | 托盘右键 → 退出应用；或设置面板 → 退出 |

**快捷键**：`Enter` 添加 · `Esc` 依次退出编辑 → 清空输入 → 收起设置 → 隐藏窗口

### 编辑任务的细节

- **双击标题**直接进入行内编辑，光标落在末尾，输入框自动全宽替换标题
- **`Enter` 保存**，**`Esc` 取消**（放弃修改，但不会误触隐藏窗口），点别处失焦也自动保存
- **内容清空后回车 = 删除该条**，不用再单独点垃圾桶
- 首尾空格自动裁剪，最多 200 字（与新增一致）
- 同一时刻只有一行处于编辑态；去编辑另一行时，上一行自动提交
- 已完成的任务同样可以改名，不会因此被取消勾选

## 设置面板

顶栏齿轮图标打开，包含：

- **透明度** 40%–100% 无级调节，调低可让待办半透明地浮在其他窗口上方
- **开机自启** 开关，登录 Windows 后自动出现在桌面
- **窗口模式** 快速切换悬浮 / 普通
- **退出程序**

## 数据存在哪里

任务与窗口状态保存在本机应用数据目录：

```
%APPDATA%\今日待办\
├── state.json       窗口位置、尺寸、模式、透明度
└── Local Storage\  任务清单
```
- 完全离线，不联网、不上传
- 关闭窗口不丢数据；只有托盘「退出应用」才真正结束进程

## 安装到桌面（推荐）

双击 `dist/今日待办-安装程序-1.0.2.exe`，按向导走完即可。

安装后你会得到：

- **桌面快捷方式**「今日待办」，带自定义蓝色对勾图标
- **开始菜单快捷方式**，可在搜索框输入「今日待办」直接启动
- **控制面板可卸载**（设置 → 应用 → 今日待办）

安装位置默认 `%LOCALAPPDATA%\Programs\今日待办`，也可以点「更改目录」自己选。**单用户安装，全程不需要管理员权限**。

卸载时任务数据会保留（`deleteAppDataOnUninstall: false`），重装后待办还在。若要彻底清除，手动删除 `%APPDATA%\今日待办`。

## 免安装版

`dist/今日待办-免安装-1.0.2.exe`：不写注册表、不建快捷方式、不占安装目录，双击即用，可放 U 盘带走。

> 两种方式的首次运行都可能遇到 Windows SmartScreen 提示"未知发布者"，点「更多信息」→「仍要运行」。这是未购买代码签名证书的正常现象，不代表程序有问题。

## 图标

冷蓝渐变圆角方块 + 白色对勾，与程序内勾选框同源。

包含 9 种尺寸帧（16/20/24/32/40/48/64/128/256），分别用于任务栏小图标、桌面快捷方式、Alt+Tab 切换器等场景。16px 下已针对性加粗勾线并保留抗锯齿过渡，不会糊成一团。

## 技术要点

- **Electron 33**，`contextIsolation: true` + `nodeIntegration: false`，渲染进程无文件系统与 Node 访问权
- 悬浮透明窗口通过 `transparent` + `skipTaskbar` + `setAlwaysOnTop('floating')` 实现，并 `setVisibleOnAllWorkspaces` 支持虚拟桌面
- 拖动用 CSS `-webkit-app-region: drag`，比 IPC 位移更跟手、无延迟累积；所有交互元素显式声明 `no-drag`
- 模式切换采用「销毁并按新模式重建窗口」，不是改属性——因为 `frame` / `transparent` 创建后不可变
- 窗口坐标越界保护：拔掉副屏后自动拉回主屏可见区域；边缘 14px 自动吸附
- 单实例锁：重复启动会激活已有窗口，不会开出第二个
- 开机自启带 `--autostart` 参数，启动后静默驻留托盘，不弹窗抢焦点
- **图标嵌入走 `afterPack` 钩子**：在应用目录打包完成、安装程序生成之前用 rcedit 写入，确保安装包、便携包、程序本体三者图标一致

## 关于首次打包的环境坑

本机非管理员权限下，electron-builder 解压 `winCodeSign` 会因 macOS 符号链接失败，只能加 `-c.win.signAndEditExecutable=false` 跳过资源编辑——但该开关会连带跳过图标嵌入。所以本项目用 `afterPack` 钩子 + `rcedit` 单独补上。

代价是 exe 无代码签名。要消除 SmartScreen 提示，需自备代码签名证书。
